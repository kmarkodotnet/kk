# docs/done – az elkészült fejlesztési feladatok

Ide kerül minden olyan feladat fájlja, amelyet a `/dev` parancs (vagy kézi munka)
végigvitt: a kód elkészült, a tesztek lefutottak, és a Definition of Done minden pontja
teljesült.

A fájl a mozgatáskor egy **lezáró szakasszal** egészül ki: mikor készült el, mely
parancsok futottak milyen eredménnyel, és melyik commit tartalmazza.

Ez a mappa a projekt elvégzett munkájának naplója. A hátralévő munka a
[`../backlog/`](../backlog/) mappában van.

> Jelenleg üres – a fejlesztés most indul.
